# Projet 2 - Débugger une application Java

## But du programme

Ce programme permets de compter le nombre de symptomes présent dans une liste, et ce pour chaque symptome.
Le programme sors un fichier `result.out` contenant pour chaque symptome son nombre d'occurence, de plus les symptomes sont triés par ordre alphabétiques.

## Démarrage

Pour démarrer l'application il suffit de lancer par le fichier `Main.java` car ce dernier contient la méthode main

## Prérequis

Il est nécessaire d'avoir un fichier `symptoms.txt` contenant un symptome par ligne pour exécuter le programme

> Exemple de fichier `symptoms.txt`
> ```
> cough
> insomnia
> headache
> insomnia
> constricted pupils
> nausea
> cough
> shortness of breath
> blurred vision
> dizziness
> low blood pressure
> ```
>
> Exemple de fichier `result.out`
> ```
> dialated pupils: 4
> dizziness: 5
> dry mouth: 8
> fever: 7
> headache: 3
> high blood pressure: 10
> ```
